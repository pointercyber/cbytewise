# CBytewise — Programming in C Study & Quiz

A React + Vite exam revision website based on the uploaded Programming in C module notes, practical programs, and Diploma Examination question papers for November 2022, 2023, 2024 and 2025.

**Developed by Kalidas R** · GitHub: https://github.com/pointercyber · Buy me a coffee: https://www.buymeacoffee.com/kalidasr

## Features

- Required sponsor-link click gate before Study Mode or Simulated Quiz. The user must click the sponsor link before the continue button unlocks. The app cannot independently verify whether the external page was actually viewed.
- Study mode with search, module filters, expandable answers and source references.
- Four module groups: C fundamentals; arrays and strings; pointers and dynamic memory; structures and files.
- 50 MCQs with shuffled options, timer, hints, question navigation, results, answer review and retry.
- Past-paper reference cards for the 2022–2025 question papers.
- Responsive white UI and “Developed by Kalidas R” credit.

## Source coverage note

The uploaded module notes cover Module 2 (Arrays), Module 3 (Pointers), and Module 4 (Structure and File). The uploaded exam papers include questions from Module 1, so Module 1 study answers are built around those exam questions; a separate Module 1 notes PDF was not among the uploaded files. The study guide gives source references where an answer corresponds to a past-paper question.
